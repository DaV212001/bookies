# Bookies

Bookies is an open-source Flutter reading app for organizing an EPUB library,
reading comfortably, and sharing chapter discussions and notes.

## Features

- EPUB library and reader
- Adjustable reading themes and text size
- Chapter navigation with discussion threads
- Highlights, annotations, and community features

## Getting started

Install Flutter, then run:

```bash
flutter pub get
flutter run
```

Run the analyzer and tests with:

```bash
dart analyze
flutter test
```
